Choose one electrical theory calculator and work with it in a focused space. Every tool keeps its formulas, assumptions, units, and calculated values together so you can test a prediction instead of treating the result as a black box.

:::caution[Educational scope]
These are idealized theory models, not electrical-design, code-compliance, protection, conductor-sizing, or field-work tools. Verify practical work through the applicable code edition, local requirements, manufacturer data, and qualified supervision.
:::

<ToolDirectory />

## A useful way to work with a calculator

1. Predict whether the result should be larger, smaller, leading, or lagging.
2. Change one input and explain the new result in words.
3. Sketch the related circuit, impedance triangle, or power triangle.
4. Check the units and test a limiting case.
5. Record any mismatch between your prediction and the model.
